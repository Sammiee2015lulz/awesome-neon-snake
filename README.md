# ⚡ Awesome Neon Snake ⚡

A fun and cool neon-styled classic Snake game built with pure HTML, CSS, and vanilla JavaScript.

## Features
- Neon glow effects and dark theme
- Score tracking with local high score persistence
- Speed increases as you score more
- Keyboard controls (Arrow keys or WASD)
- Responsive and simple to play

## How to Play
1. Open `index.html` in any modern browser
2. Use arrow keys or WASD to control the snake
3. Eat the pink food to grow and score points
4. Avoid walls and yourself!
